Política de privacidad de finanzasVZ

finanzasVZ no crea cuentas ni envía datos financieros a servidores propios. Los gastos, notas y copias se guardan solo en tu dispositivo. Para mostrar la tasa de cambio consulta DolarAPI y, como respaldo, el BCV. Para comprobar actualizaciones consulta la API pública de GitHub Releases; la descarga del APK solo ocurre si tú pulsas «Actualizar», desde GitHub o desde un servidor local opcional en tu red. Ninguna de esas peticiones envía tus movimientos, notas, PIN ni datos de huella. No hay anuncios ni analítica. Contacto: joseesteves199930@gmail.com.
